## مقدمه

DuckDrive 
 در یک چت تلگرام، فضای ذخیره‌سازی شخصی ابری برای شما فراهم می‌کند. فایل‌هایی که به ربات می‌فرستید، در سرور محلی ذخیره، در صورت نیاز تکه‌تکه (Chunk) می‌شوند و در یک دیتابیس SQLite مانیتور می‌شوند.

دسترسی به این درایو از طریق:

- **وب‌UI** (HTML/JS) با لیست فایل‌ها، آمار، آپلود کشیدن‑و‑رها (drag‑and‑drop) و پیش‌نمایش رسانه‌ها.
- **WebDAV** (قابلیت مونت شدن به‌عنوان یک درایو در Windows, macOS و Linux).
- **دستورات تلگرام** برای آپلود/دانلود/اشتراک‌گذاری سریع.

تمام ارتباطات از طریق پروتکل MTProto تلگرام انجام می‌شود و می‌توانید از پروکسی MTProto یا SOCKS5 برای عبور از فیلترها استفاده کنید.

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name CyDrive --icon=icon.ico --add-data "icon.ico;." gui.py
```

> **توضیح پارامترها:**
> - `--onefile` : همه‌ی وابستگی‌ها در یک فایل اجرایی می‌شود.
> - `--windowed` : برنامه بدون کنسول اجرا می‌شود (برای برنامه‌های گرافیکی).
> - `--icon=icon.ico` : آیکون برنامه.
> - `--add-data "icon.ico;."` : فایل آیکون را به باینری اضافه می‌کند.
> - `gui.py` : نقطهٔ ورود برنامه (در این پروژه `gui.py` یا همان `app.py` بسته به نحوهٔ راه‌اندازی کاربرد دارد؛ اگر از `app.py` استفاده می‌کنید، نام فایل را تغییر دهید.)

## پیکربندی

### 1️⃣ `config.json`

در اولین اجرا، برنامه یک **ویزارد تعاملی** (`CyDriveConfig.interactive_setup`) را اجرا می‌کند و از شما مقادیر زیر را می‌پرسد:

| پرسش | چه مقدار باید وارد کنید |
|------|------------------------|
| **Bot Token** | توکن ربات که از @BotFather دریافت می‌کنید. |
| **Chat/User ID** | شناسه کاربر یا گروه خصوصی که ربات با آن کار می‌کند. |
| **Drive Letter** (فقط در ویندوز) | حرف درایوی که می‌خواهید سوار شود (پیش‌فرض `Y:`). |
| **Enable Proxy?** | `Y` یا `N` برای فعال‌سازی استفاده از پروکسی. |
| **WebDAV / UI host** | `127.0.0.1` برای دسترسی محلی یا `0.0.0.0` برای باز کردن به بیرون. |

اجرای `python app.py` برای اولین بار به‌طور خودکار `config.json` را در ریشه پروژه می‌سازد.

#### ویرایش دستی (اختیاری)

```json
{
  "bot_token": "123456:ABCDEF…",
  "chat_id": 123456789,
  "api_id": 6,
  "api_hash": "eb06d4abfb49dc3eeb1aeb98ae0f581e",
  "storage_path": "./Telegram_Drive",
  "cache_path": "./Telegram_Cache",
  "db_path": "./cydrive_meta.db",
  "webdav_host": "127.0.0.1",
  "webdav_port": 8080,
  "web_ui_host": "127.0.0.1",
  "web_ui_port": 8088,
  "enable_web_ui": true,
  "drive_letter": "Y:",
  "auto_mount_drive": true,
  "chunk_size_mb": 1900,
  "cache_limit_gb": 20,
  "encryption_password": null,
  "enable_encryption": false,
  "enable_proxy": true,
  "proxy_file": "proxies.txt",
  "proxy_timeout": 5.0
}
```

### 2️⃣ `proxies.txt` (اختیاری)

اگر پروکسی فعال کردید، هر خط یک پروکسی را به یکی از قالب‌های زیر توصیف می‌کند:

```
# مثال‌های MTProto (کلید ساده)
host.example.com:443:dd1234567890abcdef...

# مثال MTProto با FakeTLS (کلید ee)
tg://proxy?server=host.example.com&port=443&secret=eeabcdef...

# SOCKS5 (با یا بدون نام کاربری/رمز عبور)
socks5://username:password@host.example.com:1080
# یا به‌صورت ساده
host.example.com:1080
```

اگر این فایل وجود نداشته باشد، برنامه در اولین اجرا یک الگوی نمونه‌ی اولیه می‌نویسد.

## اجرای برنامه

```bash
python app.py
```

### چه اتفاقی می‌افتد؟

1. **بارگذاری پیکربندی** (یا اجرای ویزارد اگر فایل موجود نباشد).
2. **بارگذاری و تست پروکسی‌ها**؛ پروکسی سالم انتخاب می‌شود.
3. **اتصال به تلگرام** (با پروکسی انتخابی یا مستقیم).
4. **راه‌اندازی وب‌UI** در `http://<web_ui_host>:<web_ui_port>` (پیش‌فرض 8088).
5. **راه‌اندازی سرویس WebDAV** در `<webdav_host>:<webdav_port>` (پیش‌فرض 8080).
6. در ویندوز، اگر `auto_mount_drive` فعال باشد، درایو (مثلاً `Y:`) به‌صورت خودکار سوار می‌شود.

برای خاتمه‌ی برنامه، `Ctrl+C` را فشار دهید؛ برنامه به‌صورت پاکیزه منابع را آزاد می‌کند.

## دسترسی به وب‌UI و WebDAV

| سرویس | آدرس | پورت پیش‌فرض |
|-------|------|--------------|
| **وب‌UI** | `http://127.0.0.1:8088` (یا host/port دلخواه) | `8088` |
| **WebDAV** | `http://127.0.0.1:8080` | `8080` |
| **API داخلی** | `http://<web_ui_host>:<web_ui_port>/api/...` | — |

**وب‌UI** شامل:

- لیست فایل‌ها (نام، حجم، وضعیت، تاریخ آخرین تغییر).
- ناحیه‌ی کشیدن‑و‑رها برای آپلود.
- پیش‌نمایش تصویر/ویدیو/صدا.
- آمار لحظه‌ای (تعداد فایل، حجم ذخیره شده، وضعیت پروکسی).

**WebDAV** می‌تواند به‌عنوان یک درایو معمولی توسط سیستم‌عامل مونت شود (بخش بعدی را ببینید).

## نقشه‌برداری پلتفرم‑های مختلف (Mount)

### ویندوز

DuckDrive از سرویس **WebClient** ویندوز استفاده می‌کند. در زمان اجرا، درایو تنظیم‌شده (پیش‌فرض `Y:`) به‌صورت خودکار سوار می‌شود. برای حذف سوار شدن به‌صورت دستی:

```powershell
net use Y: /delete
```

> **توجه:** برنامه در اولین اجرا، رجیستری را برای پشتیبانی از فایل‌های بزرگ (حداکثر 4 GB) بهینه می‌کند؛ برای این کار نیاز به دسترسی ادمین است.

### macOS

- باز کنید **Finder → Go → Connect to Server** (⌘K)
- وارد کنید: `dav://127.0.0.1:8080`

یا از ترمینال:

```bash
mount_webdav http://127.0.0.1:8080 ~/DuckDrive
```

### لینوکس

#### گزینه ۱ – `gio` (پیشنهادی)

```bash
gio mount dav://127.0.0.1:8080
```

#### گزینه ۲ – `davfs2`

```bash
sudo apt-get install davfs2          # برای اوبونتو/دبیان
mkdir -p ~/DuckDrive
mount -t davfs http://127.0.0.1:8080 ~/DuckDrive
```

#### گزینه ۳ – `rclone`

```bash
rclone config create duckdrive webdav url http://127.0.0.1:8080
rclone mount duckdrive: ~/CyDrive --daemon
```

پس از سوار شدن، درایو همانند هر پوشه‌ی محلی رفتار می‌کند؛ می‌توانید فایل‌ها را کپی، حذف یا ویرایش کنید و این تغییرات به‌صورت خودکار به تلگرام همگام می‌شوند.

## ساختار پروژه (به‌صورت کلی)

```
DuckDrive/
├─ app.py               # نقطه ورود؛ ربات تلگرام، وب‌UI، WebDAV

├─ proxies.txt          # لیست پروکسی‌ها (در صورت نیاز)
├─ Telegram_Drive/      # کش محلی فایل‌های آپلود شده
├─ Telegram_Cache/      # کش برای Chunkهای بزرگ
├─ cydrive_meta.db      # دیتابیس SQLite برای متادیتا
├─ static/
│   ├─ index.html
│   ├─ style.css
│   └─ app.js
├─ requirements.txt     # وابستگی‌های پایتون
└─ README.md            # همین فایل
```

ماژول‌های کلیدی (درون `app.py`):

| ماژول | نقش |
|-------|------|
| `ProxyManager` | تجزیه، تست و چرخش پروکسی‌ها. |
| `CyDriveConfig` | بارگذاری/ذخیرهٔ تنظیمات؛ ویزارد تعاملی. |
| `MetaDatabase` | لایهٔ SQLite برای مدیریت فایل/Chunk. |
| `CacheManager` | مدیریت کش محلی و فرار حافظه بر پایه LRU. |
| `FileChunker` | تقسیم/ادغام فایل‌های بزرگ. |
| `CyCrypto` | رمزنگاری AES‑GCM برای کش (اختیاری). |
| `WindowsMounter` / `UnixMounter` | کمک‌کننده‌های سوار شدن بسته به OS. |
| `TelegramSyncEngine` | کلاینت Telethon؛ دریافت پیام، پردازش فایل، حلقهٔ health‑check. |

## پرسش‌های متداول و رفع اشکال

### 1️⃣ ربات وصل نمی‌شود / پیغام «Database is locked»

- حلقه‌ی **health‑check** در صورت بروز قفل SQLite سشن تلگرام را ریست می‌کند.
- اگر مشکل ادامه داشت، برنامه را متوقف کنید، فایل‌های `*.session-journal` را حذف کنید (برنامه هنگام شروع مجدد این کار را انجام می‌دهد) و دوباره اجرا کنید.

### 2️⃣ بارگذاری فایل بزرگ شکست می‌خورد

- فایل‌های بزرگتر از `chunk_size_mb` (پیش‌فرض 1900 MB) به‌صورت خودکار تقسیم می‌شوند.
- مطمئن شوید فضای کافی در `Telegram_Cache/` دارید؛ می‌توانید `cache_limit_gb` را در `config.json` بالا ببرید.

### 3️⃣ پروکسی کار نمیکند

- برنامه را با `--debug` یا حالت `HAS_RICH=True` اجرا کنید تا لاگ دقیق تست پروکسی‌ها نشان داده شود.
- فرمت خط در `proxies.txt` را بررسی کنید؛ از قالب‌های مستند استفاده کنید.
- برای پروکسی‌های `ee…` (FakeTLS) حتماً بسته‌ی `TelethonFakeTLS` نصب شده باشد.

### 4️⃣ مانت WebDAV به‌خطای “403 Forbidden” می‌رسد

- در ویندوز، سرویس **WebClient** باید فعال باشد (`sc query webclient`).
- در macOS / Linux، URL و پورت را دوباره چک کنید و اطمینان حاصل کنید فایروال مسدود نکرده باشد.

### 5️⃣ می‌خواهم ذخیره‌سازی را رمزنگاری کنم

1. در `config.json` مقدار `"enable_encryption"` را به `true` تغییر دهید.
2. مقدار `"encryption_password"` را به پسورد مطلوب خود تنظیم کنید (یا `null` بگذارید تا در زمان اجرا درخواست شود).
3. برنامه را ریستارت کنید؛ کش جدید به‌صورت رمزنگاری شده ذخیره می‌شود.

> **هشدار:** پسورد در فایل ذخیره نمی‌شود؛ باید خودتان آن را به خاطر بسپارید.

### 6️⃣ به‌روزرسانی به نسخهٔ جدید

```bash
git pull origin main
pip install -r requirements.txt --upgrade
# دیتابیس قبلی سازگار باقی می‌ماند.
```
